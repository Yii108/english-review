# 英文複習本 English Review

自己的英文筆記＋每日抽考＋間隔複習。

- 新增單字、片語、句型、文法筆記（可批次貼上、自動辨識類別）
- 輸入英文自動翻譯成你選的語言（免費翻譯服務 MyMemory）
- 點單字看音標、聽發音（免費字典 dictionaryapi.dev，含真人錄音）
- 每日抽考：選擇題、看意思拼字、聽音拼字、例句填空，依答對／答錯次數自動安排下次複習
- 例句填空會從免費字典找新例句；抽考時可自動唸出單字和例句
- 筆記庫搜尋：英文、意思、例句、筆記、音標都能搜，關鍵字會標示出來
- 離線可用：打開過一次後，沒網路也能抽考、新增、看筆記
- 筆記存在你自己的瀏覽器，可複製備份

使用：打開 https://yii108.github.io/english-review/ ，手機可「加入主畫面」當 App 用。
